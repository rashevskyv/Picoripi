# Zelda: Twilight Princess — довідник тегів BMG

Джерело: декомпіляція гри (dusklight), файли `include/d/d_msg_class.h` (константи
`MSGTAG_*`), `src/d/d_msg_class.cpp` (обробники `do_tag` / `do_color` / `do_scale` /
`do_character` / `do_outfont`, таблиця `getFontCCColorTable`).

## Формат тегу в редакторі

```
{escape:ГРУПА:ДАНІ}
```

- **ГРУПА** — номер групи тегів (0, 3, 4, 5, 6, 255).
- **ДАНІ** — hex-байти: перші 2 байти — код тегу в групі, далі (якщо є) аргументи.
  Приклад: `{escape:0:0007002d}` = група 0, тег `0x0007` (PAUSE), аргумент `0x002d` = 45 кадрів.

Аліаси з `aliases.json` — лише зручні імена для відображення в редакторі; у файлах
даних завжди зберігається сира escape-форма.

- [x] Перед будь-яким AI-запитом `{escape:0:0000}` і `{escape:0:0022}` передаються як `Link` та `Epona` (також підтримано їхні родові форми); `INSTANT` не плутається з іменем.

## Група 255 — колір, масштаб, фурігана

### Колір: `{escape:255:0000XX}` (MSGTAG_COLOR)

XX — індекс у таблиці кольорів гри (`getFontCCColorTable`, d_msg_class.cpp):

| Індекс | Колір | HEX | Наш аліас |
|---|---|---|---|
| 00 | білий (за замовчуванням)* | `#ffffff` | `{color:white}` |
| 01 | червоний | `#f07878` | `{color:red}` |
| 02 | зелений | `#aadc8c` | `{color:green}` |
| 03 | синій | `#a0b4dc` | `{color:blue}` |
| 04 | жовтий | `#dcdc82` | `{color:yellow}` |
| 05 | світло-блакитний | `#b4c8e6` | — |
| 06 | фіолетовий | `#c8a0dc` | `{color:purple}` |
| 07 | білий (дублікат) | `#ffffff` | `{color:gray}` (насправді білий!) |
| 08 | помаранчевий | `#dcaa78` | `{color:orange}` |

\* Колір 00 («за замовчуванням») залежить від типу вікна (fukiKind):
- звичайна розмова — білий `#ffffff`;
- вікно Мідни (fukiKind 13) — блакитний `#82e6e6`;
- вікно духа світла (fukiKind 8) — білий;
- fukiKind 14 — зелений `#96dc64`.

Індекс > 8 трактується грою як білий.

### Масштаб: `{escape:255:0001XXXX}` (MSGTAG_SCALE)

XXXX — u16, масштаб у **відсотках** (hex): `0064` = 100%, `0096` = 150%, `00c8` = 200%.
У прев'ю редактора також працює зручна форма `{scale:150}`.

Правила масштабування (з `do_scale` / `do_character` / `jmessage_tMeasureProcessor`):

1. Базовий розмір тексту фіксований — задається layout-ресурсом вікна
   (`zelda_message_window_text.blo`), а не кількістю тексту.
2. Тег масштабу діє з місця появи. Ефективний масштаб = тег × distanceScale
   (distanceScale = 1.0 для вікна розмови; менше 1.0 для «бульбашок» над NPC вдалині).
3. Ширина символу масштабується: просування = charSpace + width × round(scale×fontSize)/cellWidth.
   **charSpace і lineSpace НЕ масштабуються.**
4. Збільшений гліф центрується по вертикалі відносно звичайного рядка
   (зсув на половину різниці висот).
5. **Масштаб > 1.0 автоматично скидається до 1.0 в кінці рядка** (перенос \n),
   крім спеціальних типів сторінок. Масштаб < 1.0 зберігається.
6. Якщо на сторінці є масштаб > 1.0, сторінка вміщує на один рядок менше
   (3 замість 4 для англійської версії).

### Фурігана: `{escape:255:0002...}` (MSGTAG_RUBY)

Дрібний текст над словом (використовується лише в японській версії).

## Метрики вікна розмови (для звірки прев'ю)

- Сторінка англійської версії — **4 рядки** (`n_e4line` у layout; японська — 3 з фуріганою).
- Розмір шрифту, charSpace і lineSpace вікно бере з `zelda_message_window_text.blo`
  (у репозиторії декомпіляції самих .blo немає — вони йдуть з дампу гри).
- Вікно Мідни має власний розмір шрифту 23×22 (`mBoxMidna_fontSize` у HIO-налаштуваннях).
- Текстбокс розтягується код ом в 1.2 раза по ширині (`mpTm_c[i]->resize(1.2f * ...)`),
  тобто фактична зона тексту ширша за пейн layout-у.

## Ширина тегів-іконок

Усі іконки (кнопки, стрілки, мітки, серце, нота тощо — все, що малює
`COutFont_c` через `do_outfont`) у грі мають однаковий розмір **24×24 px**
(× активний масштаб тексту), і просування курсора після іконки =
`24 × масштаб + charSpace` (`jmessage_tRenderingProcessor::do_outfont`).
Тому в `font_map.json` всі теги-іконки мають ширину 24. Теги-підстановки
тексту (`{F:Link}`, `{timer}`, лічильники групи 5, гліфи групи 4) мають
змінну ширину — вона рахується за фактичним текстом.

## Вигляд тексту у вікні розмови (тінь, сяйво, яскравість)

З `d_msg_object.cpp` (HIO), `d_msg_scrn_talk.cpp`, `d_msg_scrn_light.cpp`, `d_msg_out_font.cpp`:

- **Прозорість вікна** розмови: `mBoxTalkAlphaP = 0.9`. Текст зсунутий усередині
  вікна на `mTextPosX = +4.5`, `mTextPosY = 0`.
- **Яскравість тексту**: основний текстовий пейн модулюється TEV-білим
  `(200,200,200)` (`mBoxStartWhite[0]`) — «білий» текст гри насправді `#c8c8c8`;
  кольорові теги теж множаться на цю яскравість.
- **Тінь**: окремий пейн-копія тексту (`t4_s`) з TEV-білим `(0,0,0,255)` —
  тобто чисто чорний текст позаду основного. Усі тіні іконок у `COutFont_c::draw`
  малюються зі зсувом **+2,+2 px** — той самий зсув використовує і тінь тексту.
- **Сяйво («moya», drawPikari/dMsgScrnLight)**: за КОЖНИМ символом малюється
  анімований спрайт світіння з ресурсу `zelda_message_window_text_light.blo`.
  Колір залежить від типу вікна:
  - звичайна розмова — золотавий, TEV white `(225,210,110)`, альфа 160;
  - вікно Мідни — синій `(40,110,180)`, альфа 120;
  - дух світла — яскраво-жовтий `(255,255,110)`, альфа 210, плюс ефект
    «пікарі» (спалах на кожній новій літері);
  - тип 4 — зелений `(70,150,0)`, альфа 150.
  Загальна сила сяйва для розмовного вікна: `mBoxTalkHaloAlpha = 1.0`
  (для вовка — 0.3, для предметів — 0).
