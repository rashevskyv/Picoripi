# Gen IV text encoding (charmaps)

`charmap_dp_hgss.txt` (Diamond / Pearl, HeartGold / SoulSilver) and `charmap_platinum.txt` (Platinum) hold
code-to-character lines only: `HEX=character` for a text code, `HEX={COMMAND}` for a control code.

Provenance: Gen IV text encoding: code-to-character facts, independently verified against the ROM text banks; no decomp source text or code is included; pret decomps carry no licence, so only these facts are used.
