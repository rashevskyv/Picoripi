All notable changes to the **Picoripi** project will be documented in this file.

## [Unreleased]

- Project Manager: **Share project...** packs a project (project folder, translation files, linked series glossaries; no game files, sessions or caches) into one `.zip` with its paths made relative and outside paths cleared; **Import shared project...** unpacks such a zip into a folder the receiver chooses and points it at the receiver's own game files.
- Project Manager virtual groups can own a shared series glossary with create, link, replace, and unlink actions; member projects automatically inherit the glossary across translation and series tabs without duplicate entries, preserving explicit project links and ancestor discovery during moves and unlinks.
- Project Manager groups: moving a project, deleting a folder or importing no longer fails when a member's project file is missing (it is logged and skipped), and nothing is written when there is no group glossary to change; removing a project from the manager clears its group glossary link; the open project's series chain is built on the sync worker, not the UI thread. Tests in `tests/test_ui/test_project_manager/test_group_glossary.py`.

- Font Editor keeps nested reads and decodes serial, ignores cancelled or obsolete loads, and prepares formatted font sheets in memory on a worker; loading now has an immediate indicator, cancellation and responsive glyph-table progress, with linear map lookup for large Yo-kai Watch fonts and safe cleanup after closing.

- Yo-kai Watch discovers nonblank reference languages from loose tables and existing ARC0 archives on a cancellable worker; reference tabs show only languages with text for the selected row, preserving the active language and existing fan references; message window preview is restored with game font glyphs, layout styles and tag styling; duplicate context and layout fit hooks protect cross-platform translation reuse between 3DS and Switch.

- New Project accepts an existing extracted game folder separately from translations, validates its text tables on a worker, reports unsupported image plugins accurately, and offers same-wizard key-file replacement and retry for missing or unsuitable Nintendo 3DS keys.
- Opening a project from the Project Manager shows a progress dialog from the first moment (it appeared only after the project file sync, so the window looked frozen); the file sync now runs on a worker.
- Reference tab: a plugin that does not support reference patches no longer shows it, and the default label is "Reference" (it was "Reference (RU)" for every game); the issue scan no longer writes two debug lines per block and per problem.
- 3DS manual preview: the page is drawn at a whole-number zoom of the console pixels (no smoothing when it is enlarged, smoothing only when it must shrink), so it no longer looks smeared when the panel is resized.
- 3DS manuals: the same paragraph text in two manuals shares one translation (D46): the plugin's `get_duplicate_context_for_string` replaces the window and the translation context in the duplicate key, and `get_text_fit_problems_for_string` refuses a place whose layout the text does not fit (repeated translations, memory rows, series rows, glossary fill and batch followers; a refused follower stays untranslated and the status bar says so).
- Wii discs: the common key is read at 0x114 of `keys.bin` (it was 0x158, the NAND AES key), so a real Wii disc decrypts; `test_wii_image.py` checks the 0x114 offset.
- `setup.bat` and `run.sh` change to their own folder first (`run.bat` already did): started with "Run as administrator" the current folder is `C:WindowsSystem32`, where `setup.bat` deleted and made `.venv` and then failed with "Could not open requirements file: requirements.txt". `setup.bat` also checks that `requirements.txt` and `main.py` are beside it and that Python is in PATH, and prints the folder and the Python version. Test in `tests/test_tools/test_tasks.py`.
- Skies of Arcadia (GameCube and Dreamcast): the byte budget is per script (the sum of its text segments, changed lines padded to steps of 4 bytes). A changed line of an over-budget script is flagged with the script's budget; a save keeps the typed text; the build refuses the script and names its lines (`scripts.budget_of`, `build.changed_files`); the fixed-size mode is removed. In-game proof of a net-zero marker line (80 bytes for 40) on Dreamcast (Flycast) and GameCube (Dolphin), both private and muted; the user guide lists the two plugins (EN, UK).
- Skies of Arcadia scripts: labels are code-relative (a label sits at code start plus its value), so the writer no longer cuts text at fake labels and relocates labels with the right base; branch operands after `0x0b` and `0x90` move with their targets; the aligned-word heuristic is removed. A script's text now has a script-level budget: a line may grow only when another line of the same script gives the bytes back (the total length and the tail stay put; spaces pad the rest). Growth that moves the tail froze the Dreamcast game (ME201A, in-game 2026-10-18). Tests in `tests/test_core/test_skies_script.py`.
