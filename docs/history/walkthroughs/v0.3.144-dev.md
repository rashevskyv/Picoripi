## Що зроблено

- **2.0** Вимірювальний скрипт аудиту — у репозиторії; показники «до» збережено.
- **2.1** Правила запиту — сталий блок у системному промпті (`prompt_composer/instructions.py`) замість
  блоку `INSTRUCTIONS`, що збирався наново в кожному повідомленні. Системний промпт однаковий для всіх
  фрагментів. Нагадування при повторі цитує справжню помилку. Редактор промптів показує правила під рядком
  `--- REQUEST RULES … ---`, але зберігає лише частину над ним.
- **2.2** Сусідні рядки контексту беруться за справжнім розташуванням: вибіркові переклади більше не
  показують рядки 0–3 першого блока, проєктні прогони отримали сусідів узагалі.
- **2.3** На старті блочного перекладу промпт більше не складається для всього набору (двічі); збираються
  лише замінники тегів, а перегляд у редакторі будується з першого фрагмента.
- **2.4** Видалено те, що ніколи не працювало: `NarrativeLedger` і шлях сесій для перекладу. README та
  вікі 2, 8, 11 виправлено.
- **2.5** Менше даних на рядок: спільні значення розмітки — раз у `layout_defaults`; невідомий мовець не
  надсилається; одна референсна мова на рядок (налаштування `max_reference_languages`); редактор-рецензент
  отримує трійки `{id, text, translation}`. Кожен рядок JSON — в одному рядку тексту.
- **2.6** Глосарій фрагмента — лише за його власним текстом плюс мовці й учасники сцени; у пакетних запитах
  компактні картки персонажів замість повних профілів MemPalace.
- **2.7** Рідний JSON-режим для api.openai.com, рідного Gemini та Ollama (для проксі Web2API — без змін).
