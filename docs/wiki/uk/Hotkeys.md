# Клавіатурні скорочення

**Мова:** [English](../Hotkeys.md) · Українська

Ця сторінка містить клавіші Picoripi за завданнями. У кожному рядку є шлях у меню, тож ту саму дію можна знайти мишею. Клавіші, що працюють лише в окремому вікні, описані в розділі 9.

- `Ctrl+Shift+S` означає: затисніть `Ctrl` і `Shift`, потім натисніть `S`.
- **Немає в меню** означає, що дія має лише клавішу або кнопку.
- Довідка **Клавіатурні скорочення** (`F1`) показує коротший список. Див. кінець сторінки.

## 1. Проєкт і файл

| Дія | Скорочення | Шлях у меню |
|---|---|---|
| Новий проєкт... | `Ctrl+N` | Файл → Новий проєкт... |
| Відкрити проєкт... | `Ctrl+O` | Файл → Відкрити проєкт... |
| Менеджер проєктів... | `Ctrl+Shift+M` | Файл → Менеджер проєктів... |
| Зберегти зміни | `Ctrl+S` | Файл → Зберегти зміни |
| Налаштування... | `Ctrl+P` | Файл → Налаштування... |
| Клавіатурні скорочення | `F1` | Довідка (праворуч угорі) → Клавіатурні скорочення |

## 2. Редагування тексту

| Дія | Скорочення | Шлях у меню |
|---|---|---|
| Скасувати введення | `Ctrl+Z` | Правка → Скасувати введення |
| Повторити введення | `Ctrl+Y` або `Ctrl+Shift+Z` | Правка → Повторити введення |
| Зберегти переклад | `Ctrl+T` | Правка → Зберегти переклад |
| Відновити переклад | `Ctrl+Shift+T` | Правка → Відновити переклад |
| Вставити текст блоку | `Ctrl+Shift+V` | Правка → Вставити текст блоку |
| Автоматично виправити поточний рядок | `Ctrl+Shift+A` | Правка → Автоматично виправити поточний рядок |
| Сховати теги | `Ctrl+Q` | Вигляд → Сховати теги |

У полі **Редагований** `Enter` починає новий рядок. В деяких іграх `Shift+Enter` і `Ctrl+Enter` вставляють символ, який визначають правила гри.

## 3. Пошук

| Дія | Скорочення | Шлях у меню |
|---|---|---|
| Знайти (показати або сховати рядок пошуку) | `Ctrl+F` | Правка → Знайти... |
| Знайти далі | `F3` | Немає в меню. Кнопка **Далі** в рядку пошуку |
| Знайти раніше | `Shift+F3` | Немає в меню. Кнопка **Назад** у рядку пошуку |
| Розширений пошук | `Ctrl+H` | Правка → Розширений пошук... |

У рядку пошуку `Enter` виконує **Далі**. `F3` і `Shift+F3` працюють лише тоді, коли активне головне вікно.

## 4. Проблеми і перескановування

| Дія | Скорочення | Шлях у меню |
|---|---|---|
| Наступний рядок із проблемою | `Ctrl+Down` | Немає в меню. Стрілка над полем **Редагований** |
| Попередній рядок із проблемою | `Ctrl+Up` | Немає в меню. Стрілка над полем **Редагований** |
| Пересканувати все | `Ctrl+Shift+R` | Правка → Пересканувати все |

## 5. Переходи між рядками, блоками і папками

| Дія | Скорочення | Шлях у меню |
|---|---|---|
| Наступний рядок (будь-який) | `Alt+Down` | Немає в меню |
| Попередній рядок (будь-який) | `Alt+Up` | Немає в меню |
| Наступний або попередній рядок у **Рядки в блоці** | `Down` або `Up` без інших клавіш | Немає в меню. Не працює, коли вибрано кілька рядків |
| Наступний блок | `Alt+Shift+Down` або `Ctrl+Page Down` | Навігація → Навігація до наступного блоку |
| Попередній блок | `Alt+Shift+Up` або `Ctrl+Page Up` | Навігація → Перехід до попереднього блоку |
| Наступна папка | `Alt+Shift+Right` | Навігація → Навігація до наступної папки |
| Попередня папка | `Alt+Shift+Left` | Навігація → Назад до попередньої папки |

Picoripi також реєструє чотири стрілки з `Alt+Shift` у Windows. Вони працюють, навіть коли Windows могла б перехопити їх першою.

## 6. Перегляд і закладки

| Дія | Скорочення | Шлях у меню |
|---|---|---|
| Прев’ю | `Ctrl+Shift+P` | Вигляд → Прев’ю |
| Додати закладку... | `Ctrl+B` | Закладки → Додати закладку... |
| Очистити всі закладки | немає | Закладки → Очистити всі закладки |

## 7. Глосарій, ШІ та інструменти сюжету

| Дія | Скорочення | Шлях у меню |
|---|---|---|
| Відкрити глосарій... | `Ctrl+G` | Інструменти → Відкрити глосарій... (також кнопка **Глосарій…**) |
| Відкрити чат штучного інтелекту | `Ctrl+Shift+C` | Кнопка на панелі інструментів |
| AI: перекласти поточний рядок | `Ctrl+Alt+T` | Інструменти → AI: перекласти поточний рядок |
| AI: перекласти виділені рядки | `Ctrl+Alt+L` | Інструменти → AI: перекласти виділені рядки |
| AI: перекласти весь блок | `Ctrl+Alt+B` | Інструменти → AI: перекласти весь блок |
| **AI Reset Translation Session** | немає | Інструменти → **AI Reset Translation Session** |
| Переглянути контекст історії... | `Ctrl+I` | Інструменти → Переглянути контекст історії... |
| **MemePalace Context Builder...** | `Ctrl+M` | Інструменти → **MemePalace Context Builder...** |
| **MemePalace Database Viewer...** | `Ctrl+Shift+I` | Інструменти → **MemePalace Database Viewer...** |

Пункти **Інструменти** без клавіші: **Localization Pipeline**, Редактор шрифтів, Текстури, Студія розмітки скриптів, Підготувати глосарій, Спільна робота, Прогрес.

## 8. Миша з клавішею-модифікатором

| Клік | Де | Що відбувається |
|---|---|---|
| `Ctrl`+клік | Термін глосарію в **Оригіналі** | Відкриває запис глосарію для редагування |
| `Ctrl`+клік | **AI-переклад** або **AI-варіант** | Спершу відкриває редактор запиту |
| `Ctrl`+клік | **Автовиправлення** | Дає вибрати правила |
| `Shift`+клік | **Автовиправлення** | Виправлення в межах сторінки. Текст не переходить на іншу сторінку |
| `Ctrl` + коліщатко миші | Дерево блоків | Змінює розмір шрифту дерева |
| Правий клік | **Редагований** | Вставляє тег. Якщо текст виділено, тег обгортає його |

## 9. Окремі вікна

Ці клавіші працюють лише тоді, коли їхнє вікно активне.

| Вікно | Клавіша | Дія |
|---|---|---|
| Глосарій | `Ctrl+S` | Зберігає глосарій |
| Глосарій | `Esc` | Закриває вікно |
| Глосарій, діалог редагування терміна | `Enter` | Підтверджує запис |
| Менеджер проєктів | `Ctrl+F` | Переносить курсор у поле пошуку |
| Менеджер проєктів | `Esc` | Очищає текст пошуку. Наступний `Esc` закриває вікно |
| Студія розмітки скриптів | `Ctrl+F` | Переносить курсор у поле пошуку |
| Студія розмітки скриптів | `Ctrl+M`, `Ctrl+S`, `Ctrl+P`, `Ctrl+T`, `Ctrl+B`, `Ctrl+I` | **Mark**, **Structure**, **Спікер**, **Text**, **Breaker**, **Ігнорувати** |
| Студія розмітки скриптів | `Ctrl+Z` / `Ctrl+Y` | Скасувати / повторити |
| Студія розмітки скриптів | `Ctrl+Shift+Up` / `Ctrl+Shift+Down` | Змінює глибину вибраних елементів структури |
| Студія розмітки скриптів | `F2` | Перейменовує елемент структури |
| Редактор шрифтів | `Ctrl+S` | Зберігає |
| Редактор шрифтів | Стрілки / `Ctrl` + стрілки | Рух між гліфами / рух пікселів гліфа |
| Редактор шрифтів | `Ctrl+C` / `Ctrl+V` | Копіює / вставляє значення гліфа в таблиці |
| Редактор шрифтів | `Esc` | Спершу завершує редагування клітинки. Інакше закриває вікно |
| Текстури | `Ctrl+O`, `F5` | Відкрити, Оновити |
| Текстури | `Ctrl+E`, `Ctrl+I` | **Export PNG**, **Import PNG** |
| Чат з ШІ | `Ctrl+Enter` / `Enter` | Надсилає повідомлення / новий рядок |
| Чат з ШІ | `Ctrl+Shift+R` | Натискає кнопку **Повторити** |

## 10. Клавіші, які використовуються в кількох місцях

Реагує лише вікно, яке активне. У меню головного вікна жодна клавіша не призначена двічі.

| Клавіша | Головне вікно | Інше вікно |
|---|---|---|
| `Ctrl+P` | Налаштування | **Speaker** (Студія) |
| `Ctrl+S` | Зберегти зміни | Зберегти (Глосарій, Редактор шрифтів), **Structure** (Студія) |
| `Ctrl+T` | Зберегти переклад | **Text** (Студія) |
| `Ctrl+B` | Додати закладку | **Breaker** (Студія) |
| `Ctrl+M` | **MemePalace Context Builder** | **Mark** (Студія) |
| `Ctrl+I` | Переглянути контекст історії | **Ignore** (Студія), **Import PNG** (Текстури) |
| `Ctrl+Shift+R` | Пересканувати все | Повторити (Чат з ШІ) |
| `Ctrl+Enter` | Вставляє символ гри в **Редагований** у деяких іграх | Надсилає (Чат з ШІ) |

`Ctrl+Alt+T`, `Ctrl+Alt+L` і `Ctrl+Alt+B` — це клавіші ШІ. На клавіатурах із AltGr `Ctrl+Alt` може ввести символ. Це не перевірено. Плагіни можуть додавати свої клавіші. Ця сторінка їх не перевіряє.

## Довідка з клавіатурних скорочень

**Довідка → Клавіатурні скорочення** (`F1`) показує 22 клавіші в трьох групах: загальні (6), редактор (8) і навігація (8). Кожна клавіша з цього списку відповідає коду. У довідці немає:

- `Ctrl+N`, `Ctrl+O`, `Ctrl+Shift+M`, `Ctrl+T`, `Ctrl+Shift+T`, `Ctrl+B`, `Ctrl+Shift+P`, `Ctrl+Shift+R`
- `Ctrl+M`, `Ctrl+I`, `Ctrl+Shift+I`, `Ctrl+Alt+T`, `Ctrl+Alt+L`, `Ctrl+Alt+B`
- `Ctrl+Page Up` і `Ctrl+Page Down`
- Клавіш окремих вікон (розділ 9)

## Загальні ситуації

- **Клавіша нічого не робить.** Зробіть активним вікно, яке має реагувати. Клавіші Студії не працюють у головному вікні.
- **Ctrl+S зберіг лише глосарій.** Було активне вікно Глосарію. Клікніть головне вікно і натисніть `Ctrl+S` ще раз.
- **Ctrl+Down пропускає рядки, які я очікую.** Вона переходить лише до рядків із проблемою. Для кожного рядка використовуйте `Alt+Down`.
- **Ctrl+Shift+R у чаті з ШІ не перескановує.** У вікні чату вона натискає **Повторити**. Для перескановування використовуйте **Правка → Пересканувати все** в головному вікні.
- **F3 нічого не робить.** Зробіть активним головне вікно. `F3` не працює в інших вікнах.
- **Потрібна клавіша для кнопки.** Наведіть курсор на кнопку. Багато підказок показують клавішу в дужках.
- **Ctrl+Alt дає символ.** Ваша клавіатура може використовувати AltGr. Скористайтеся пунктом меню.
