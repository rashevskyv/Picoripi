# Віртуальна навігація і прев’ю

**Мова:** [English](../6_Virtual_Navigation_and_Preview.md) · Українська

Ліве дерево **Blocks** змішує фізичні файли з похідними виглядами. Збирається в `ui/updaters/block_list_updater.py`. Фізичні рядки — джерело правди для save/load. Віртуальні теки лише **групують** наявні рядки.

---

## Фізичне дерево

- Вкладені теки. Стиснуті шляхи архівів виглядають як `bmgres4.arc / zel_00.bmg`.
- Рисочки попереджень (кольоровий gutter) і лічильники `(N)` на файлах і стиснутих рядках. Дані рисочки лежать на айтемі (UserRole+20), щоб підписи не подвоювались як `Name (1) (1)`.
- Незбережене `*` на файлах і батьках.
- Зелена заливка прогресу: частка перекладу. Порожні / пробільні / лише-теги оригінали не рахуються.
- **Show Unsaved Only** над деревом ховає файли без незбережених правок. Лише сесія: перезапуск завжди знімає галочку (`AppDataStore.from_snapshot` вимикає обидва unsaved-фільтри).

Розгортання чи згортання **фізичної** теки лише зберігає стан відкрито/закрито. Воно **не** перебудовує все дерево і не перезаповнює кожен блок.

Клік по фізичному файлу (`UserRole >= 0`) завжди вантажить рядки цього файлу, навіть якщо батько виглядає як агрегат.

## Похідні корені

Стабільні імена на UserRole+4:

| Корінь | Значення |
|--------|----------|
| **Story** | Акти / розділи / сцени з MemePalace + комбо Chapter |
| **Speakers** | Рядки за розв’язаним спікером, плюс `None` для непризначених **непорожніх** рядків |
| **Items** | Item-get / каталожний текст, прив’язаний до довідкових предметів |
| **Windows** | Групи за типом ігрового вікна повідомлення |
| **Notated** | Рядки з явною нотаткою перекладача (`UserRole == -5`) |

Порожній BMG-паддинг лишається у **фізичному** файлі. Віртуальні корені пропускають порожні рядки (`_is_blank_row`). Тип, у якому були б лише порожні, не з’являється.

Клік по віртуальному листу вантажить лише його відображені пари `(block, string)`.

**⟳ Rebuild virtual folders** на тулбарі дерева перебудовує Speakers / Chapters / Items з поточних сюжетних даних. Файли перекладу не чіпає.

Перетягування рядків на віртуальний лист призначає цю грань (спікер, розділ, …). Корінь **Chapters** і теки Act не мають правого кліку.

## Список Strings проти редактора

- Клік по рядку в **Strings in block** прив’язує Original + Editable.
- **Hide empty strings** згортає підряд порожні в плейсхолдер (цей фільтр **відновлюється** з сесії).
- **Show Unsaved Only** на списку рядків **не** відновлюється.
- **Show Warnings Only** + **Warnings: X / Y** використовує id проблем, увімкнені в Detection плагіна.

## Візуальне прев’ю

**View → Preview** (`Ctrl+Shift+P`), також дія Preview на тулбарі. Під Editable: `BfnPreviewWidget` + `BfnPreviewWindowBar`.

Коли плагін оголошує `message_window_preview` (Twilight Princess BMG), прев’ю може малювати хром talk / item-get / sign з **локального** дампу гри. Репозиторій не постачає ассети Nintendo. Сторінка `n/N` і original/translation (`T`/`O`) на тій панелі.

**Global → Enable Live Preview** вимикає живий симулятор, щоб зменшити лаги.

**Не** чекайте рамок вікон TP без легального локального дампу і плагіна Zelda BMG.

## Поля Story Context

Над Editable: **Window:**, **Chapter:**, **Speaker:**, Font / Max-width. Ті самі призначення, які читають віртуальні теки.

- Подвійний клік **Window:** → фізичний блок гри.
- Подвійний клік **Chapter:** → віртуальний Chapter.
- Подвійний клік **Speaker:** → віртуальний Speaker або Item.
- `None` у Speaker знімає призначення.

**Не** вигадуйте спікерів для порожніх слотів паддингу; цих рядків немає в Speakers.
