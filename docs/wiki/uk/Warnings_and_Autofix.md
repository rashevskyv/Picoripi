# Попередження й автовиправлення

**Мова:** [English](../Warnings_and_Autofix.md) · Українська

Ця сторінка пояснює попередження, які Picoripi показує для кожного рядка. Тут сказано, як знайти рядки з проблемами і як їх виправити. Читайте її, коли рядок має кольорову смужку або коли треба виправити багато рядків одразу.

![Головне вікно](../img/getting_started/07_editor_uk.jpg)

## Що таке рядок із проблемою

Picoripi перевіряє кожен рядок сам. Рядок із проблемою має принаймні один тип проблеми. Кожен тип має назву, колір і перевірку.

Список типів залежить від плагіна гри. Стандартні типи такі:

| Назва | Що означає |
|---|---|
| **Попередження тегу** | Кількість тегів не збігається або тег недійсний |
| **Перевищено ширину підрядка** | Підрядок ширший за жорстку межу |
| **Порожній непарний підрядок** | Видимий непарний підрядок порожній або показує `0` |
| **Порожній перший рядок сторінки** | Перший рядок сторінки порожній, а наступні — ні |
| **Короткий підрядок** | Підрядок не закінчується розділовим знаком, але для наступного слова є місце |
| **Підрядок з одного слова** | У підрядку лише одне слово |
| **Підрядок з одного слова (не початок)** | У підрядку лише одне слово, і це не перший рядок вікна |
| **Погані пробіли** | Два пробіли поспіль або рядок починається з пробілу |
| **Немає пробілу біля тегу** | Немає пробілу навколо видимого тегу або між словами, розділеними тегами нульової ширини |
| **Розрив іконки з дефісом** | Тег, дефіс і слово розірвані переносом рядка |

Наведіть курсор на тип у **Налаштування → Проєкт → Виявлення**, щоб прочитати його опис.

## Кольорові смужки

- У списку **Рядки в блоці** кольорова смужка стоїть поруч із номером рядка. Кожен тип проблеми має свій колір.
- У дереві **Блоки** смужки праворуч показують типи проблем у цьому блоці.
- Колір типу однаковий у списках **Виявлення** та **Автовиправлення**.

## Перехід до наступної проблеми

| Дія | Клавіші |
|---|---|
| Наступний рядок із проблемою | `Ctrl+↓` або стрілка над **Редагований** |
| Попередній рядок із проблемою | `Ctrl+↑` або стрілка над **Редагований** |
| Наступний рядок, з проблемою чи без | `Alt+↓` |
| Наступний блок | `Alt+Shift+↓` |

Пошук іде в межах поточного блоку. Дійшовши до кінця блоку, він починається знову з його початку. Якщо в блоці немає рядка з проблемою, вибір не змінюється.

## Показати лише рядки з проблемами

1. Увімкніть **Лише з попередженнями** у рядку фільтрів над **Рядки в блоці**.
2. Натисніть **Попередження: X / Y** і виберіть типи для показу.

Перше число — кількість вибраних типів. Друге число — кількість типів, увімкнених у **Виявлення**. Тип, вимкнений у **Виявлення**, не рахується.

## Налаштування виявлення й автовиправлення

Перейдіть до **Налаштування (`Ctrl+P`) → Проєкт**.

- **Виявлення** має одне поле для кожного типу проблеми. Вимкнене поле вимикає перевірку цього типу.
- **Автовиправлення** має два загальні прапорці:
  - **Вирівняти речення за оригінальною розміткою сторінки**
  - **Запобігати додаванню порожніх рядків відступу під час розбиття на сторінки**
- Нижче, у блоці **Увімкніть або вимкніть автовиправлення окремих проблем:**, є по одному полю для кожного типу. Вони визначають, які типи можна виправляти.

Типово всі поля **Виявлення** увімкнені. Усі поля **Автовиправлення** теж увімкнені, крім трьох: **Попередження тегу**, **Підрядок з одного слова** і **Підрядок з одного слова (не початок)**. Два загальні прапорці вимкнені. Плагін може задати інші типові значення.

## Кнопка Автовиправлення

Кнопка **Автовиправлення** стоїть над полем **Редагований**. Вона виправляє поточний рядок.

| Дія | Результат |
|---|---|
| Клік | Виправляє рядок за всіма увімкненими типами |
| Ctrl+клік | Відкриває список. Ви вибираєте, які типи виправити |
| Shift+клік | Виправляє кожну сторінку окремо. Текст не переходить через межу сторінки |
| Ctrl+Shift+клік | Відкриває список, а потім виправляє кожну сторінку окремо |
| `Ctrl+Shift+A` | Виправляє рядок за всіма увімкненими типами. Список не відкривається |

Модифікатори діють лише для кнопки. Комбінація клавіш завжди запускає звичайне виправлення.

## Виправити всі рядки

Перейдіть до **Інструменти → Виправити всі стрічки...**.

1. Діалог показує типи проблем. Спочатку в ньому стоять вибори з **Автовиправлення** у налаштуваннях.
2. Позначте потрібні типи. Якщо не позначено жодного, програма зупиняється й показує повідомлення.
3. Натисніть **OK**. Програма виправляє всі рядки у фоновому режимі.

Перед запуском збережіть роботу клавішами `Ctrl+S`.

## Пересканування

- **Пересканувати все** (`Ctrl+Shift+R`) перебудовує ширини й попередження для всього проєкту. Кнопка на панелі робить те саме.
- Щоб пересканувати один блок, клацніть його правою кнопкою в дереві **Блоки**.
- На великому проєкті перше сканування триває довго. Програма показує вікно поступу.

Використовуйте **Пересканувати все** після змін шрифтів, тегів або меж ширини. Так само зробіть, коли смужки виглядають неправильно.

## Правопис

Перевірка орфографії не належить до типів проблем.

- Перейдіть до **Налаштування → Правопис**. Виберіть **Мова словника:**.
- Натисніть **Керування словниками...**, щоб завантажити або видалити словники. У тому самому вікні видно слова, які ви додали.
- Щоб додати слово, використайте **Додати до словника** з меню перевірки орфографії.
- Список **Слова з помилками:** показує слова, які знайшла перевірка. Клацніть слово, щоб переглянути його. Головний редактор перейде до його рядка.

Про інші вкладки налаштувань див. [Посібник з налаштування](../4_Configuration_Guide.md).

## Плагіни з власними типами проблем

Плагін перелічує свої типи проблем у файлі `config.py`. Він використовує спільні перевірки з `plugins/common/problem_rules/`. Плагін може додати власні типи, змінити їхні назви й кольори та задати свої типові налаштування. Плагін також може прибрати спільний тип, який його гра не використовує. Механізм і кроки описано в [Посібнику розробника плагінів](../3_Plugin_Developer_Guide.md).

## Типові ситуації

**Попередження не зникає, хоча я виправив рядок.**
- Натисніть **Пересканувати все** (`Ctrl+Shift+R`).
- Перевірте, що рядок збережено клавішами `Ctrl+S`.

**Потрібного типу проблеми немає в списку.**
- Плагін не використовує цю перевірку.
- Плагіни визначають власні типи. Див. [Посібник розробника плагінів](../3_Plugin_Developer_Guide.md).

**Автовиправлення змінило більше, ніж я хотів.**
- Натисніть `Ctrl+Z`, щоб скасувати останню зміну.
- Наступного разу використайте Ctrl+клік і позначте лише потрібні типи.

**Автовиправлення перенесло текст через межу сторінки.**
- Натисніть **Автовиправлення** з Shift. Кожна сторінка виправляється окремо.

**Автовиправлення нічого не робить для певного типу.**
- Перевірте **Автовиправлення** в **Налаштування → Проєкт**. Тип із вимкненим полем не виправляється.
- Перевірте й **Виявлення**. Тип, який не знайдено, теж не виправляється.

**Список попереджень занадто довгий.**
- Увімкніть **Лише з попередженнями**.
- Натисніть **Попередження: X / Y** і виберіть один-два типи.

**Виправити всі рядки не змінило потрібний рядок.**
- Перевірте, що тип позначено в діалозі.
- Перевірте, що тип увімкнено в **Виявлення**.

**Виправити всі рядки змінило занадто багато.**
- Про відновлення попередньої роботи див. [Збереження, скасування й відновлення](../Saving_and_Recovery.md).

**Слово позначено як помилку, хоча воно правильне.**
- Натисніть **Додати до словника** для цього слова.
- Перевірте, що **Мова словника:** — та мова, якою ви пишете.

**Перше сканування повільне.**
- Дочекайтеся, поки закриється вікно поступу.
- Великий проєкт триває довше за малий.
