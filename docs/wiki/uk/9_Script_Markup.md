# Script Markup Studio

**Мова:** [English](../9_Script_Markup.md) · Українська

Відкривається з **Tools → Script Markup Studio…**, з кроку пайплайну **Mark up the script**, або з фіолетової кнопки **R** біля редакторів (стрибок до місця, прив’язаного до поточного ігрового рядка).

Реалізація: `ui/script_markup_studio_dialog.py`. Логіка: `core/script_markup/` (без Qt). HTML довідки в самому вікні — опис продукту; ця сторінка йде за ним плюс меню/шорткати з того ж файлу.

---

## Навіщо

Перетворює сирий вокзру на стандартизований скрипт, який споживають збирачі MemePalace:

- `[Chapter:]` / `[Location:]` / `{Action:}` / `SPEAKER: text`

Працюєте в **одному** кольоровому вигляді сирого скрипта. Другої панелі, яку треба синхронізувати, немає. **Preview result…** показує готовий файл; **Export** його записує.

Кольори (`_KIND_COLORS`):

| Kind | Колір | Значення |
|------|--------|----------|
| Chapter | червонуватий | Заголовок розділу |
| Location | блакитний | Локація |
| Action | бурштиновий | Ремарка / дія |
| Speaker / dialogue | зелений | Репліка (сусідні блоки спікера чергують зелений/бірюзовий) |
| Ignored / dropped | сірий | Не експортується |
| Narration / blank | білий | Некласифіковано / порожньо |

## Режими

Типово — **Hierarchy markup**. **Picoripi rules** і **Custom recipe** живуть у **Advanced ▾ → Legacy tools**.

| Режим | Навіщо |
|-------|--------|
| **Hierarchy markup** (типово) | Ручні мітки дерева з глибиною. Кожна мітка має глибину, тип, підпис/текст, колір. Експорт — канонічний Markdown |
| **Picoripi rules** (legacy) | Власний парсер вокзру програми (спікери й сцени). Краще для вже структурованих скриптів |
| **Custom recipe** (legacy) | Налаштовувані правила + навчання на прикладах, для брудних сирих вокзру |

Вікно стадіями: **1. Source — 2. Markup — 3. Review — 4. MemPalace**.

**File ▾:** Open script..., Open project..., Save, Save As..., Close. **Auto-fill ▾:** Join selected structures; Continue from marked examples... (локально, без AI); AI mark missing.... **Advanced ▾:** Template, Export (**Preview result…**, **Export game_script.md…**), Change Type Color..., Legacy tools.

**Ctrl+M** у **головному вікні** — MemePalace Context Builder. **Ctrl+M всередині Studio** мітить виділення (або зберігає правку вузла). Це різні команди.

---

## Воркфлоу

1. **Script → Open script...** — завантажити сирий вокзру.
2. *Hierarchy:* мітити виділення, переглянути дерево скрипта, далі **Project**, **Template** і **Auto-fill**, коли потрібні повторювані мітки або допомога заповнення.
3. *Picoripi rules / Custom recipe:* **Start from cursor** і **End at cursor**, щоб відрізати зміст, склад і юридичний перед/післятекст.
4. *Custom recipe:* підкрутити чекбокси або навчити на прикладах.
5. Дивитись кольори і чергу Review; **Preview result…** для перевірки.
6. **Export** стандартизованого скрипта.

Майстер пайплайну знаходить наявний markup-проєкт на диску і публікує `script_markup_studio_project_path` на головному вікні, щоб Context Builder не просив знову вказати той самий файл.

## Навігація і пошук

- **Find:** текст у полі пошуку, **Enter** — наступне входження, **Shift+Enter** — попереднє. **Aa**, **Word**, `.*` уточнюють збіг.
- **Minimap:** тягнути огляд праворуч.
- **Script tree:** подвійний клік по вузлу чи пункту review стрибає на рядок джерела.

## Експорт Hierarchy Markdown

| Тип | Рендериться як |
|-----|----------------|
| Structure глибина 0 / 1 / 2 | заголовки `#` / `##` / `###` |
| Glossary | Секція джерела MemPalace; прямі діти стають категоріями (Characters, Items, Locations або власні імена) |
| Speaker + Text | Мітяться окремо, рендеряться разом: `**MIDNA**: dialogue` |
| Action | Окремий рядок у квадратних дужках: `[*Midna drops from a branch*]` |
| Unmarked | **Не** рахується зробленим у зонді статусу пайплайну |

Порожні рядки джерела не «markable». Один зайвий порожній рядок не триматиме крок пайплайну на `N / N+1` вічно.

## Хто споживає далі

- **Merge Speakers from Script…** зіставляє розмічені імена з голосовими кодами гри.
- **MemePalace Context Builder** імпортує ієрархічний таймлайн.
- Автопрохід глосарія сіє імена персонажів з розмітки (`core/glossary_build/script_seeds.py`).
- **R** на головному вікні стрибає з ігрового рядка на розмічене місце.

**Finish for MemPalace…** відмовляється йти далі, поки лишаються нерозмічені діапазони.

**Не** експортуйте і потім правте Markdown руками, якщо Studio має лишатися власником проєкту — працюйте в Studio і експортуйте знову.

**Не** пропускайте розмітку і не чекайте повного Merge Speakers чи повних сідів персонажів у глосарії.
