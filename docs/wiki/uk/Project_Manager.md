# Менеджер проєктів

**Мова:** [English](../Project_Manager.md) · Українська

Менеджер проєктів показує всі додані ігрові проєкти. Тут можна відкривати, групувати, шукати, перейменовувати,
переміщувати й поширювати проєкти. Щоб створити проєкт, читайте [Новий проєкт: усі види ігор](New_Project_Scenarios.md).

![Менеджер проєктів з розгорнутим рядком](../img/getting_started/11_manager_row_uk.png)

Натисніть **Файл → Менеджер проєктів...** або `Ctrl+Shift+M`. Вікно також відкривається під час запуску. Див. [Відкриття під час запуску](#відкриття-під-час-запуску).

## Панель кнопок

| Кнопка | Що робить |
|---|---|
| **+ Додати проєкт** | Меню: **Новий проєкт...**, **Додати наявний проєкт...**, **Імпорт проєктів з папки...**, **Імпортувати спільний проєкт...** |
| **Нова папка...** | Створює папку у списку. На диску нічого не з'являється |
| **Груповий глосарій...** | Задає спільний глосарій папки. Див. [Груповий глосарій](#груповий-глосарій) |
| **Емулятор...** | Задає команду емулятора для кожної платформи. Її потребує **Запустити в емуляторі** |
| **Пошук проєктів** | Фільтрує за назвою, серією, платформою, плагіном, папкою або шляхом. `Ctrl+F` ставить курсор, `Esc` очищає |
| **Список** / **Плитка** | Перемикає вигляд. Плитка показує великі піктограми |
| **Групування** | Задає розділи. Див. нижче |
| **Сортування**, **За спаданням** | Порядок проєктів у розділі |

## Групування і сортування

| Групування | Розділи |
|---|---|
| **За папкою** | Кожна папка. Проєкти без папки йдуть до **Без папки** |
| **За платформою** | Кожна платформа. Без платформи йдуть до **Без платформи** |
| **За готовністю** | **Не почато** (0 %), **У процесі**, **Готово** (100 %), **Невідомо** |
| **За обсягом тексту** | **Малий** (до 1 000 рядків), **Середній** (до 10 000), **Великий**, **Невідомо** |
| **Без групування** | Один розділ: **Усі проєкти** |

**Сортування** працює за **Назва проєкту**, **Рядки**, **Платформа**, **Готовність** або **Змінено**. Розділ
**Відкрито останнім** завжди стоїть першим.

## Папки

Папки існують лише в Менеджері. Клацніть папку правою кнопкою, щоб вибрати **Перейменувати папку...** або
**Видалити папку...**. Клацніть проєкт правою кнопкою, щоб вибрати **Перемістити до папки...**. **Видалити папку**
переносить її проєкти на верхній рівень. Файли проєктів не видаляються.

## Колонки і статус

Колонки у вигляді списку: **Назва проєкту**, **Платформа**, **Серія**, **Плагін**, **Прогрес**, **Відкрито останнім**, **Статус**.

У колонці **Статус** можуть бути такі слова, розділені комами:

| Статус | Значення |
|---|---|
| **Відкривається** | Файл проєкту читається |
| **Немає файлу** | Файлу проєкту немає на диску |
| **Не читається** | Файл проєкту не вдається прочитати |
| **Плагін відсутній** | Плагін гри не встановлено |
| **Потребує уваги** | Інша проблема. Список є в розгорнутому рядку |
| **оновлення...** | Рядок сканується знову |
| **Зібрано**, **Перевірено в грі** | Ваші позначки. Див. [Зібрано і Перевірено](#зібрано-і-перевірено) |

**Потребує уваги** охоплює відсутній шлях до оригінальних файлів, відсутній шлях до перекладу, відсутній плагін
і файл проєкту, який не читається.

## Розгорнутий рядок

Клацніть стрілку ліворуч від рядка. Там є шлях, платформа, плагін і файли гри з ролями, серійний глосарій,
кількість рядків, відсоток перекладу і дати, таблиця ресурсів (**Текстові файли**, **Файли шрифтів**,
**Файли текстур**, **Інші файли**), позначки **Зібрано** і **Перевірено в грі**, а також кнопки **Відкрити**,
**Показати в папці**, **Прибрати з менеджера**, **Змінити значок...**, **Поділитися проєктом...**, **Зібрати мод**,
**Експортувати мод**, **Запустити в емуляторі**.

## Значки

Picoripi бере значок гри під час створення лише для 3DS і GameCube. **Змінити значок...** зберігає ваше зображення
як `icon.png` (256 пікселів) у теці `picoripi` проєкту. **Прибрати значок** видаляє цей файл, але не файли гри.

## Перейменувати, перемістити, прибрати

| Дія | Що змінює |
|---|---|
| **Перейменувати...** | Лише назву в Менеджері. Файл проєкту зберігає свою назву |
| **Перемістити до папки...** | Папку в Менеджері. Також змінює груповий глосарій у файлі проєкту |
| **Прибрати з менеджера** | Прибирає проєкт зі списку. Файли лишаються на диску. Picoripi не видаляє проєкт з диска |
| **Показати в папці** | Відкриває теку проєкту у Провіднику |

Щоб видалити проєкт з диска, видаліть його теку у Провіднику. **Прибрати з менеджера** питає підтвердження.
Якщо проєкт не відкрито, пункт також очищає груповий глосарій у файлі проєкту.

## Імпорт проєктів

**Додати наявний проєкт...** додає файл `project.uiproj`, який уже є на диску.

**Імпорт проєктів з папки...** шукає у теці файли `picoripi\project.uiproj`, теки резервних копій пропускає. Позначте
проєкти і натисніть **Імпортувати**. Вже наявні проєкти мають напис **Уже в менеджері**. Для нової серії створюється папка.

**Імпортувати спільний проєкт...** відкриває файл `.zip`. Див. нижче.

### Поширення проєкту

**Поділитися проєктом...** пакує проєкт в один файл `.zip`. Пакет містить теку проєкту, файли перекладу і прив'язані
серійні глосарії. Оригінальних файлів гри в ньому **немає**. Незбережені зміни в редакторі в пакет не потрапляють,
тому спершу збережіть їх.

Під час імпорту Picoripi просить ваші оригінальні файли гри. Ім'я файлу відправника показано для довідки.
**Запустити в емуляторі** потребує команди з **Емулятор...**.

## Груповий глосарій

Груповий глосарій є одним глосарієм, спільним для всіх проєктів папки.

1. Виберіть папку або групу і натисніть **Груповий глосарій...**.
2. Оберіть **Новий спільний глосарій...**, **Прив'язати спільний глосарій...** або **Змінити спільний глосарій...**.
   Щоб відв'язати, натисніть **Відв'язати спільний глосарій**. Файл не видаляється.

Кожен проєкт зберігає прив'язку у своєму файлі. Перенесення проєкту до папки або з неї оновлює прив'язку.

## Зібрано і Перевірено

- **Зібрано**: ви зібрали гру.
- **Перевірено в грі**: ви перевірили переклад у грі.

Ставте їх прапорцями в розгорнутому рядку. Picoripi сам їх не ставить. Зберігаються у файлі проєкту.

## Де зберігаються дані

| Файл | Де лежить | Що містить |
|---|---|---|
| `project_manager.json` | Тека даних | Список, папки, вигляд, глосарії папок |
| `project_index.json` | Тека даних | Кеш картки і кількості рядків кожного проєкту |
| `project.uiproj` | Тека проєкту | Сам проєкт, зокрема позначки Зібрано і Перевірено |
| `icon.png` | Тека `picoripi` проєкту | Ваш значок, якщо ви його задали |

Теку даних задають у **Файл → Налаштування (Ctrl+P) → Загальні → Розташування даних...**. Файли гри не копіюються.

## Сканування і кеш

Вікно сканує кожен проєкт під час відкриття в окремому процесі. Проєкт читається знову, лише коли змінюється його файл,
плагін або файли джерел. **Скасувати сканування** зупиняє сканування, збережені результати лишаються. **Сховати**
ховає смугу прогресу, сканування триває.

## Відкриття під час запуску

Picoripi відкриває проєкт, який був відкритий останнім, якщо його файл існує. Інакше відкривається Менеджер.
Якщо закрити Менеджер без відкритого проєкту, програма закривається.

## Типові ситуації

**Список порожній.**
- Проєктів ще немає. Натисніть **+ Додати проєкт → Новий проєкт...**.

**Проєкт має статус Немає файлу.**
- Його файл `project.uiproj` перенесли або видалили. Поверніть його або приберіть проєкт з Менеджера.

**Проєкт має статус Плагін відсутній.**
- Плагін гри не встановлено в цій копії Picoripi. Встановіть або оновіть Picoripi.

**Я випадково прибрав проєкт.**
- З диска нічого не видалено. Натисніть **Додати наявний проєкт...** і виберіть його `project.uiproj`.

**Сканування повільне або зависло.**
- Натисніть **Скасувати сканування**. Відкрийте вікно знову.
