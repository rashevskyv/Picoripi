# Як вести цю вікі

**Мова:** [English](../7_Maintaining_This_Wiki.md) · Українська

## Одне місце на факт

Англійські файли в `docs/wiki/` — джерело правди. Українські в `docs/wiki/uk/` — переклад тих самих сторінок, не друга правда.

| Який Python-файл реалізує контроль | `2_API_Reference.md` | `uk/2_…` |

| Ця таблиця | цей файл | `uk/7_…` |

**Авторитет:** поточний Python/UI. Якщо старі `docs/*.md` розходяться з кодом — правити англійську вікі з коду, потім українську копію.

## Коли змінюється код

Після зміни, видимої користувачеві, або зміни налаштувань:

1. Знайдіть рядок у таблиці вище.
2. Виправте англійську сторінку (і карту в README, якщо перемістилася точка входу).
3. Виправте `docs/wiki/uk/` — файл із тією самою назвою, той самий абзац. Назви контролів у **обох** мовах — як у UI (англійською).
4. У CHANGELOG — рядок лише про зміну **поведінки**; у вікі — тривале «як користуватися».
5. Якщо контрол перейменовано, пошукайте в `docs/wiki` стару англійську назву.

Агенти: після такої роботи або на прохання оновити документацію викликайте навичку `update-wiki` (`/update-wiki`). Перед правкою сторінки перечитайте файл коду, який вона описує.
