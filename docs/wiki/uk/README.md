# Вікі Picoripi (українською)

**Мова:** [English](../README.md) · Українська

Посібник для перекладачів і авторів плагінів. Пишеться з **поточного коду**, а не зі старих `docs/*.md`. Кореневий `README.md` — карта репозиторію.

Коли змінюється поведінка програми, оновлюйте **англійську** сторінку-власника ([7](7_Maintaining_This_Wiki.md)), потім її український близнюк у цій теці. Назви кнопок і пунктів меню беріть з `locales/uk.json`, так вони виглядають в українському інтерфейсі. Ролі Base game, Update і DLC лишаються англійськими.
