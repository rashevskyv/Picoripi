У межах цього завдання було виправлено проблеми з примусовим ресканом та перерахунком ширини шрифтів, а також усунено баг із миттєвим показом діалогового вікна завершення до реального завершення асинхронного процесу.

### Що було зроблено

1. **Виправлено час показу діалогового вікна успішного перерахунку**:
   - У методі `trigger_recalculate_widths` (файл `ui/main_window/main_window_actions.py`) оновлення текстових вікон та показ діалогового вікна `QMessageBox.information("Recalculation Complete", ...)` перенесено у внутрішній колбек `on_recalculate_completed`.
   - Тепер це вікно з'являється виключно після того, як асинхронний фоновий процес сканування завершує роботу на 100%.

2. **Забезпечено примусовий рескан (обхід та інвалідація кешу)**:
   - До методу `_perform_initial_silent_scan_all_issues` (файл `handlers/issue_scan_handler.py`) додано новий параметр `force: bool = False`.
   - При `force=True` метод ігнорує наявний кеш (`cache = None`) та видаляє файл кешу з диска (`issues_cache.json`), гарантуючи повний свіжий перерахунок ширини та виявлення проблем для всіх рядків проекту, навіть якщо час зміни файлів (`mtime`) не змінився.
   - Метод `rescan_all_tags` та `trigger_recalculate_widths` оновлено для передачі `force=True`.
   - Оновлено метод-обгортку `_perform_initial_silent_scan_all_issues` в `handlers/app_action_handler.py` для підтримки та передачі параметра `force`.

3. **Розширено тестове покриття**:
   - У файл `tests/test_handlers/test_issue_scan_handler.py` додано новий юніт-тест `test_IssueScanHandler_initial_silent_scan_force`.
   - Тест перевіряє, що при виклику `_perform_initial_silent_scan_all_issues(force=True)` файл кешу успішно видаляється, кеш не зчитується, а сканування блоків запускається примусово.

# Попередні зміни

У межах цього завдання було успішно перероблено та оновлено інтерфейс вікна **Script Markup Studio** для збереження максимального робочого простору та покращення UX відповідно до зауважень користувача.

## Що було зроблено

### 1. Компактне компонування верхньої панелі
- **Об'єднання рядків**: Повністю видалено QLabel із заголовком вікна "Script Markup Studio", який дублював заголовок самого діалогу.
- **Хлібні крихтки та статус збереження на одному рівні**: Хлібні крихтки (Progress Bar) перенесені у самий верхній рядок зліва, а індикатор збереження (`Project saved ✓` / `Autosaved` / `Unsaved changes *`) розташовано у тому самому рядку праворуч.
- **Зменшення шрифтів**: Розмір шрифтів для прогрес-бару та індикатора збереження зменшено до 9px для максимальної компактності.
- **Усунення накладання тексту та кнопок**:
  - Кнопку-меню **Auto-fill ▾** перенесено на панель керування (`control_row`) зліва від кнопки **Advanced ▾**, як і просив користувач.
  - Виправлено дефект, коли legacy-віджети (наприклад, `mode_combo`, `script_menu_btn`, `project_menu_btn`, `save_project_primary_btn`, `finish_mempalace_btn`, `template_menu_btn`, `recipe_menu_btn`), які створювалися з `parent=self`, але не додавалися до макетів, відображалися у верхньому лівому кутку вікна (координати 0, 0) і накладалися поверх прогрес-бару.
  - Метод `_update_mode_controls` вмикає видимість цих кнопок залежно від вибраного режиму (наприклад, `self.template_menu_btn.setVisible(True)`). Через це вони знову з'являлися поверх прогрес-бару.
  - **Рішення**: Для всіх невідображуваних віджетів примусово встановлено геометрію за межами екрану: `widget.setGeometry(-2000, -2000, 0, 0)`. Тепер, даже коли метод `_update_mode_controls` встановлює їм статус `setVisible(True)`, вони рендериться за межами вікна і не перекривають прогрес-бар.

### 2. Реорганізація пошукового рядка та статус-індикатора редагування
- **Очищення та ергономіка**:
  - Напис `Raw script:` видалено зі звичайного стану, щоб розвантажити інтерфейс.
  - Поле пошуку **Find:** переміщено на самий початок лінії (у лівий кут `raw_header`), що є звичним місцем для користувача.
  - Розмір поля пошуку `search_edit` розширено (встановлено `setSizePolicy(Expanding, Fixed)`) — тепер воно динамічно розтягується, займаючи весь вільний простір зліва.
  - Динамічний статусний індикатор активного редагування (`self.raw_label`) переміщено до правого краю лінії (після `addStretch`). Він з'являється тільки при виділенні нод або діапазонів і відображає кольоровий статус (наприклад, `✏️ Editing node (lines 10-15)`).

### 3. Повернення статус-бару в самий низ вікна та виправлення легенди
- **Розташування**: Легенду та статистику повернуто в самий низ діалогу під сплітером у вигляді горизонтальної статусної смуги (`bottom_status_layout`). Це забезпечує зручне звичне читання інформації.
- **Виправлення злиття плашок легенди**:
  - Через занадто жадібний регулярний вираз у `_get_legend_variants` (який захоплював додаткові стилі до лапок) Qt QLabel RichText отримував невалідний HTML/CSS і відкидав стилі плашок, через що легенда перетворювалася на суцільний злитий чорний текст: `StructureBreakerSpeakerTextActionContextItem DescriptionItemIgnored`.
  - Регулярний вираз виправлено (`span_pattern = re.compile(r'<span style="background:([^;"]+);?[^>]*>([^<]+)</span>')`), щоб він витягував виключно hex-код кольору.
  - **Додавання "повітря" між плашками**: Для гарантованого відображення відступів плашки легенди тепер об'єднуються через нерозривні пробіли `&nbsp;&nbsp;`. Це забезпечує стабільний та красивий візуальний простір між ними у QLabel.

### 4. Динамічне адаптивне скорочення легенди та статистики
- **Клас `CompactLegendLabel` (Легенда з кольорами)**:
  - Відображає кольорові плашки з літерами (або 3-літерними скороченнями, якщо вони вміщуються в поточну ширину вікна, або повними назвами).
  - Покращено контрастність: колір тексту в плашках змінено з білого на темно-сірий (`#111`), додано тонку темну рамку навколо плашок, щоб вони були чіткими та читабельними на світлому тлі.
  - **Кольоровий tooltip**: При наведенні миші на легенду спливає багатий HTML-tooltip із повною легендою та кольоровими плашками.
- **Клас `CompactStatsLabel` (Статистика)**:
  - Динамічно аналізує доступну ширину віджета та скорочує назви метрик до першої літери (`N: 5205 | D: 7`), трьох літер (`Nod: 5205 | Mxd: 7`) або показує повністю (`Nodes: 5205 | Max depth: 7`), якщо ширина дозволяє.
  - При наведенні миші показує повну версію статистики.
- **Сумісність із тестами**: Обидва класи повертають оригінальні повні тексти/HTML через метод `.text()`, що забезпечує 100% проходження існуючих тестів без потреби їх зміни.

### 5. Виправлення проблеми з вікнами на панелі задач
- **Рішення**: Додано явну передачу `self` як `parent` для всіх legacy-сумісних кнопок, меню та комбобоксів (`Save Project…`, `Finish for MemPalace…`, `Template`, `Auto-fill`, `Recipe`, `mode_combo`), що усунуло баг із появою зайвих віконець на панелі задач Windows.
